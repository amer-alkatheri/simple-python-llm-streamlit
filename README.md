# LLM Streamlit Application

A lightweight Large Language Model (LLM) application built with Python. This app uses OpenAI's API for intelligence, Streamlit for the web interface, and Dotenv for secure environment variable management.

## 🚀 Features
*   **Real-time Interaction:** Chat with OpenAI models through a sleek Streamlit UI.
*   **Secure Config:** API keys are managed via `.env` files to keep your credentials safe.
*   **Simple Architecture:** Built with plain Python and minimal dependencies.
